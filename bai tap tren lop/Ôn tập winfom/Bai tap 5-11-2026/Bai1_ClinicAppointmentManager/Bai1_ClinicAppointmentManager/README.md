# Cách chạy
Yêu cầu: Windows + .NET SDK 6 trở lên (đã thử cấu hình cho net6.0-windows, chạy được cả khi máy chỉ có runtime mới hơn như .NET 10).

Mở file .csproj bằng Visual Studio rồi nhấn F5, hoặc trong folder này chạy:

    dotnet run

Muốn nhắm .NET 10: mở file .csproj, đổi net6.0-windows thành net10.0-windows.
